# GitHub User Activity

A Python CLI tool that fetches and displays a GitHub user's recent public activity using the GitHub REST API.

## Features

- Fetches recent public GitHub events
- Displays repository names and timestamps
- Shows push, issue, pull request, repository creation, and star activity
- Displays recent commit messages and short commit IDs
